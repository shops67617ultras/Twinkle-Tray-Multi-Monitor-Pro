## System Requirements

Before installation, ensure your system meets the following criteria to guarantee optimal performance:

- **Operating System**: Twinkle Tray is designed for Windows 10 (version 1903 or later) and Windows 11. It leverages modern Windows APIs for system tray integration and background processes.
  
- **.NET Framework**: Version 4.8 or higher is required. This is typically pre-installed on recent Windows versions, but if missing, it can be downloaded from the Microsoft website.
  
- **Monitor Support**: Full functionality requires monitors with DDC-CI support. Most contemporary LCD and LED monitors include this feature, but it may need to be enabled in the monitor's on-screen display (OSD) settings. Without DDC-CI, some basic brightness controls might still work, but advanced features will be limited.
  
- **Disk Space**: At least 50 MB of free space is needed for installation, with additional space for configuration files and logs if enabled.
  
- **Processor**: A 1 GHz or faster processor is sufficient, as the application is lightweight and does not perform intensive computations.
  
- **Memory**: 512 MB of RAM or more ensures smooth operation, especially when managing multiple monitors or running scheduled tasks.
